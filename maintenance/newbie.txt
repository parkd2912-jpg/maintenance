================================================================
이 설명서를 먼저 읽어주세요
================================================================

이 키트는 "컴퓨터를 아는 사람"이 아니라 "컴퓨터를 하나도 모르는 사람"을 위해 만들었습니다.
어려운 말은 최대한 빼고, 대신 매일 보는 것들로 비유했습니다.

  · 레고 = 윈도우(컴퓨터를 돌리는 프로그램 덩어리)
  · 우리 집 = 내 컴퓨터
  · 부품 상자 = 하드디스크 안에 들어있는 파일들
  · 일꾼 = 컴퓨터 안에서 일하는 작은 프로그램들(서비스)
  · 안내 데스크 = 컴퓨터가 내부적으로 묻고 답하는 창구(WMI)

중요: 이 키트는 "지우는 프로그램"이 아닙니다.
  · 사진, 문서, 동영상, 다운받은 파일은 절대 지우지 않습니다.
  · 지울 수 있는 건 "오래된 임시 파일/캐시/휴지통"뿐이고, 지우기 전에 반드시 목록을 보여주고 물어봅니다.
  · y 를 누르지 않으면 아무것도 지우지 않습니다.

================================================================
먼저 이것만 알면 됩니다 (3줄 요약)
================================================================

1) 설치는 "install.cmd" 를 더블클릭하고 파란 창에서 "예" 를 누르면 끝납니다.
2) 그 뒤로는 아무것도 하지 않아도 6일에 한 번 컴퓨터가 스스로 점검합니다.
3) 결과는 바탕화면의 "자동유지보수_날짜.txt" 에 적힙니다(영어 윈도우에서는 "auto-maintenance_날짜.txt"이고 내용도 영어). 맨 위 3줄만 보면 됩니다.

결과 맨 위 3줄 읽는 법:
  · "정상 — 문제를 찾지 못했습니다" → 오늘은 아무 문제 없었습니다. 안심하셔도 됩니다.
  · "확인이 필요한 항목이 있습니다" → 자동으로 못 고친 게 1~2개 있다는 뜻입니다.
                                      아래 [직접 확인할 것] 을 보면 됩니다.
  · "자동으로 고친 것: N건"          → 컴퓨터가 알아서 고쳐놓았습니다. 사용자가 할 일 없습니다.

================================================================
처음 점검할 때 딱 한 번만 묻는 질문 (v1.14.8)
================================================================

"컴퓨터를 잘 아시나요?" 라고 물어봅니다.
  · Y = 아는 편이에요 → 기술적인 검사 결과를 그대로 보여줍니다.
  · N = 잘 모르는 편이에요 → 아래 비유들을 실제 결과에 붙여
        [ 초보자용 결과표 ] 로 쉽게 풀어서 보여줍니다.

한 번 고르면 다시 묻지 않고 설정에 기억합니다.
마음이 바뀌면 설치 폴더의 config.json 에서
  "explainMode": "expert"    → 기술 결과 그대로
  "explainMode": "beginner"  → 쉬운 결과표
로 바꾸고 저장하세요.

초보자용 결과표의 기호:
  OK = 통과, 아무 문제 없어요
  !! = 한 번 확인해 보세요 (당장 고장난 건 아닙니다)
  XX = 고쳐야 해요
  >> = 컴퓨터가 알아서 고쳤어요
  i  = 참고로 알려주는 내용이에요

================================================================
점검 끝에 나오는 보고서 전송 선택 (v1.14.8)
================================================================

점검이 끝나면 보고서를 GitHub(개발자들이 모인 곳)에 올릴지 묻습니다.
이 보고서는 개발자가 문제를 고치는 데 쓰이며, 개인정보는 자동으로 지웁니다.
오류 확인용으로 올라가는 내 컴퓨터 정보는 CPU 모델과 GPU 모델뿐입니다.
이름·경로·시리얼·IP 같은 개인정보는 자동으로 지우고, 보고서를 구분할 해시 앞 6자리만 함께 올라갑니다.
보내주신 문제는 대부분 다음 버전에서 수정됩니다.

  · A = 항상 자동으로 올려요 (한 번 누르면 다음부터 질문하지 않음)
  · Y = 이번만 올려요
  · N = 올리지 않아요 (기본값)

바탕화면의 "자동 유지보수 점검" 버튼을 눌러도 이 선택이 나옵니다.
컴퓨터가 스스로 도는 자동 점검(예약 실행)에서는 묻지 않습니다.
하지만 A 를 한 번이라도 눌렀다면, 그 뒤로는 예약 점검에서도
질문 없이 보고서가 자동으로 올라갑니다. (이미 동의하신 것이기 때문입니다.)

글로 "이런 점이 불편해요" 라고 남기고 싶으면
바탕화면의 "자동 유지보수 피드백" 을 실행하세요.

초보자용 결과표(N 선택)가 들어간 보고서는 GitHub 에 올라갈 때도
그대로 함께 올라가고, 본문 맨 위에 안내 줄이 붙습니다.

================================================================
40개 검사를 하나씩 쉽게 풀어서 설명합니다
================================================================

[1] OS — 운영체제 (윈도우 자체)
--------------------------------
레고로 치면 "조립 설명서 표지"입니다.
지금 내 컴퓨터에 들어있는 윈도우가 몇 번째 버전인지, 정품 스티커가 붙어 있는지 봅니다.
정품 확인은 30일에 한 번만 합니다(값이 거의 안 바뀌기 때문).
이상 있으면: 정품이 아니거나 버전 정보가 이상할 때 알려줍니다. (자동으로 고치지는 않습니다)

[2] CPU — 두뇌
--------------------------------
주방의 요리사가 지금 얼마나 바쁜지 보는 것과 같습니다.
"지금 일하는 정도"를 순간적으로 측정합니다. 0%면 쉬고 있는 것, 90%면 거의 미친 듯이 일하는 것.
이상 있으면: 숫자를 못 읽었을 때만 알려줍니다.

[3] Memory (RAM) — 책상 위 작업 공간
--------------------------------
책상이 넓으면 서류를 많이 펼쳐놓고 동시에 일할 수 있습니다.
RAM 은 그 "책상 크기"입니다. 지금 책상이 얼마나 차 있는지 봅니다.
이상 있으면: 거의 다 찼을 때 알려줍니다. (옛날 컴퓨터라면 RAM 추가를 고민하면 됩니다)

[4] Disk — 서랍장/창고
--------------------------------
집의 수납장 여유 공간을 보는 것과 같습니다.
" C: 드라이브에 100GB 남았다" = 서랍장에 아직 100GB 넣을 자리가 있다는 뜻.
여유가 드라이브 크기의 10%보다 적어지면 임시 파일을 정리할 수 있습니다.
단, !!! 삭제 전에 목록을 보여주고 A 또는 Y 를 눌러야만 지웁니다 !!!
  A = 언제나 삭제(설정에 기억해 다음부터는 물어보지 않음)
  Y = 현재만 삭제(이번 한 번만 지우고 다음에 또 물어봄)
  N 또는 Enter = 거부(아무것도 지우지 않음, 기본값)
디스크에 100MB밖에 안 남아도 자동으로 지우지 않습니다. (사용자 파일을 실수로 지우지 않게 하려는 안전 장치)
단, A 를 눌러 기억시킨 항목은 그 뒤로 자동으로 지웁니다(v1.14.8).

[5] Service — 집안의 작은 일꾼들
--------------------------------
컴퓨터 안에는 보이지 않는 일꾼이 수십 명 있습니다.
  · Spooler = 프린터에 "이 문서 출력해줘" 라고 전달하는 심부름꾼
  · WinDefend = 백신 경비원
  · EventLog = 일기장 관리인
이 일꾼이 쉬고 있으면(was Stopped) 다시 깨웁니다.
이상 있으면: 자동으로 다시 켭니다. (필수 일꾼이 꺼져 있으면 위험하다고 표시)

[6] VSS — 타임캡슐 (볼륨 섀도 복사본)
--------------------------------
컴퓨터가 "어제 이런 상태였어요" 라고 찍어둔 사진 같은 것입니다.
파일을 실수로 지웠을 때 이 사진으로 되돌릴 수 있습니다.
사진 담당 일꾼이 쉬고 있으면 다시 깨웁니다.
사진 보관함이 너무 꽉 찼는지도 봅니다.

[7] DiskHealth — 하드디스크 건강검진
--------------------------------
하드디스크가 스스로 쓴 "건강 진단서"를 읽는 것과 같습니다. (이 진단서를 SMART 라고 부릅니다)
  · 재할당 = "이 부분이 나빠져서 예비 칸으로 옮겼어요" 라는 기록
  · CRC = "데이터를 읽다가 한두 번 삐걱했어요" 라는 기록
  · Wear = SSD 의 닳은 정도 (100%면 교체 시기)
전부 0이면 아주 건강합니다. 숫자가 이전보다 늘었는지도 기억해서 알려줍니다.

[8] SysFix — 집안 기본 설정 점검
--------------------------------
컴퓨터의 "당연히 이렇게 되어 있어야 하는 설정"을 확인합니다.
  · crash dump = 컴퓨터가 쓰러졌을 때 남기는 "왜 쓰러졌는지 메모" 설정
  · 시스템 복원 = 타임머신. 없으면 새로 만들어 둡니다(20시간에 한 번)
  · 이벤트 로그 크기 = 일기장이 너무 작으면 금방 차버리므로 64MB 이상으로
  · 섀도 복사 저장소 = 위의 [6] 사진 보관함 크기
이상 있으면: 대부분 자동으로 고칩니다.

[9] SecureBoot — 현관문 보안 검사
--------------------------------
컴퓨터가 켜질 때 "이 부품은 정품이야?" 라고 확인하는 문입니다.
가짜 부품이 끼어들지 못하게 막는 장치입니다.
시스템을 해킹하려는 프로그램이 부팅 단계에서 끼어드는 걸 막습니다.
이상 있으면: 켜져 있는지만 확인하고, 꺼져 있으면 알려줍니다. (BIOS 설정은 자동으로 못 바꿉니다)

[10] Recovery — 비상구 (WinRE)
--------------------------------
컴퓨터가 고장 났을 때 들어가는 "응급실"입니다.
윈도우가 정상적으로 안 켜질 때 이곳에서 복구를 시도합니다.
응급실 문이 닫혀 있으면(비활성) 다시 엽니다.
이상 있으면: 자동으로 다시 켭니다.

[11] WMI — 컴퓨터 내부 안내 데스크
--------------------------------
다른 프로그램들이 "디스크 용량이 얼마나 남았어요?" 라고 물으면 답해주는 창구입니다.
안내 데스크가 망가지면 다른 검사들이 전부 엉터리 답을 합니다.
안내 데스크의 장부가 뒤섞였는지 확인하고, 섞였으면 정리합니다.

[12] CertStore — 신분증/여권 유효기간
--------------------------------
인터넷에서 "이 사이트 진짜요?" 라고 확인할 때 쓰는 전자 신분증입니다.
30일 안에 만료되는 신분증이 있는지 미리 알려줍니다.
이상 있으면: 알려주기만 합니다. 신분증 갱신은 주인이 직접 해야 합니다.

[13] TaskHealth — 약속한 심부름 확인
--------------------------------
"매일 새벽에 자동으로 할게요" 라고 약속한 일(예약 작업)이 제때 했는지 봅니다.
8일 넘게 안 한 일이 있으면 "이 심부름꾼이 죽었을 수 있어요" 라고 알려줍니다.
이상 있으면: 알려주기만 합니다. (예약 작업을 자동으로 다시 등록하면 설정이 어긋날 수 있어서입니다)

[14] GPU — 그림 담당 화가
--------------------------------
화면에 그림을 그리는 담당자입니다. (그래픽 카드)
"화가가 쓰는 안경"이 바로 드라이버입니다. 안경이 깨지면 그림이 이상하게 나옵니다.
최근 30일 동안 화가가 넘어진 기록(드라이버 충돌)이 있는지 봅니다.
이상 있으면: 알려줍니다. 드라이버 업데이트는 Windows Update나 제조사에서 하셔야 합니다.

[15] Battery — 노트북 연료 게이지
--------------------------------
노트북의 배터리입니다. (데스크톱이면 이 항목은 그냥 지나갑니다)
"처음보다 얼마나 닳았는지"를 퍼센트로 알려줍니다.
이상 있으면: 100% → 교체를 권합니다.

[16] WHEA — 하드웨어가 남긴 "아팠어요" 쪽지
--------------------------------
CPU/메모리/메인보드가 "전압이 순간 튀었어요", "데이터가 한 번 꼬였어요" 라고 남긴 쪽지입니다.
최근 7일치 쪽지를 봅니다.
이상 있으면: 알려줍니다. 쪽지가 계속 쌓이면 하드웨어 점검이 필요할 수 있습니다.

[17] DriverStore — 부품 설명서 보관 창고
--------------------------------
부품을 설치할 때마다 "이 부품 설명서"를 창고에 하나씩 넣어둡니다.
오래된 설명서가 쌓이면 창고가 커집니다(10GB 넘으면 경고).
이상 있으면: 알려줍니다. 실제 정리는 Windows가 알아서 합니다.

[18] BrowserCache — 인터넷 임시 보관 서랍
--------------------------------
인터넷에서 본 그림·글을 "다음에 또 필요할지 몰라서" 복사해 둔 서랍입니다.
30일 넘게 안 열어본 걸 지우면 공간이 늘어납니다.
이상 있으면: 목록을 보여주고 y 를 누를 때만 지웁니다. (지우면 사이트가 처음보다 조금 느려질 수 있어요)

[19] HostFile — 직접 쓴 주소록
--------------------------------
"이 이름은 이 주소야" 라고 컴퓨터에 직접 적어둔 메모입니다.
광고 차단할 때 여기를 쓰기도 합니다.
다만 별표(*) 와일드카드는 윈도우가 지원하지 않아서 적어도 안 먹습니다.
이상 있으면: 먹지 않는 규칙이 있다고 알려줍니다. (고치지는 않습니다 — 주인이 적은 메모라서)

[20] DNS — 전화번호 안내원
--------------------------------
"www.naver.com 주소가 뭐예요?" 라고 물으면 번호를 알려주는 안내원입니다.
안내원의 기억(캐시)이 꼬였을 수 있어서 가끔 지우고 새로 묻습니다(DNS flush).
이상 있으면: 자동으로 기억을 지웁니다. (무해합니다)

[21] AdQuiet — 광고 알림 끄기
--------------------------------
윈도우가 "추천 팁", "이 기능 써보세요" 라고 띄우는 알림을 끄는 스위치입니다.
끄면 설정·시작 메뉴에 추천 글이 안 보입니다. 그게 정상입니다.
또한 어떤 알림은 스위치가 여러 개라서, 꺼졌는지 확인하고 다시 켜지지 않게 합니다.
이상 있으면: 자동으로 다시 끕니다. 되돌리기는 "자동 유지보수 제거"(영어: "remove maintenance") 에서 가능합니다.

[22] AdFilter — 광고 전단지 차단
--------------------------------
우편함에 광고 전단지가 안 들어오게 차단 스티커를 붙이는 것과 같습니다.
기본은 꺼져 있습니다(사용자가 켜야 동작). 켜면 hosts 파일에 차단 목록을 적습니다.
100% 차단은 아닙니다. 앱 안에 그려지는 광고는 못 막습니다.
이상 있으면: 목록이 깨졌으면 다시 만들어 둡니다.

[23] Network — 인터넷 고속도로 차선 정리
--------------------------------
인터넷 선(Wi-Fi/유선)이 여러 개면 "어느 길로 먼저 갈지" 순서를 정해야 합니다.
그 순서가 엉켜 있으면 인터넷이 느려질 수 있어서 바로잡습니다.
방화벽(집 경비원)이 꺼져 있으면 다시 켭니다.
이상 있으면: 자동으로 고칩니다.

[24] GhostDev — 옛날 부품의 이름표
--------------------------------
예전에 쓰다 뺐는데 컴퓨터가 아직 "이 부품 있어요" 라고 기억하는 유령 이름표입니다.
지금은 골라내기만 하고 실제로 지우지는 않습니다(잘못 지우면 진짜 부품이 사라질 수 있어서).
이상 있으면: 알려주기만 합니다.

[25] PkgCache — 개발자 재료 창고
--------------------------------
프로그램 만드는 사람들이 쓰는 재료( pip / conda / npm / HuggingFace ) 보관 창고입니다.
여기가 2GB 넘으면 오래된 재료를 치우고, 150GB 넘으면 경고합니다.
HuggingFace 창고는 경고만 하고 절대 지우지 않습니다(용량이 너무 커서 위험).
이상 있으면: pip/conda 는 자동 정리, 그 외는 알려주기만 합니다.

[26] Startup — 문 열자 켜지는 가전제품 목록
--------------------------------
컴퓨터를 켜면 자동으로 같이 켜지는 프로그램들입니다.
처음 목록을 기억해두고, "새로 생긴 게 있네?" 하면 알려줍니다.
(자동으로 켜지는 게 많으면 컴퓨터가 느려집니다)
이상 있으면: 새 항목을 알려주고, 한 번 알린 건 다시 알리지 않습니다.

[27] RecycleBin — 휴지통
--------------------------------
버렸지만 아직 완전히 사라지지 않은 것들입니다.
30일 넘은 걸 비우면 공간이 늘어납니다.
이상 있으면: 목록을 보여주고 y 를 누를 때만 비웁니다.

[28] RegHive — 컴퓨터 설정 장부
--------------------------------
"이 프로그램은 이렇게 설정돼 있다" 를 적어둔 두꺼운 장부입니다.
장부가 500MB 넘게 부풀면 알려줍니다.
이상 있으면: 알려주기만 합니다. (장부를 함부로 고치면 컴퓨터가 고장 날 수 있어요)

[29] Defrag — 책장 정리 예약 확인
--------------------------------
책장을 정리하면 책을 빨리 찾을 수 있습니다. (HDD 에 해당. SSD 는 해당 없음)
다만 실제 정리는 윈도우가 일주일에 한 번 알아서 합니다.
여기서는 "윈도우가 정리 예약을 걸어뒀는지"만 확인합니다.
예약이 꺼져 있으면 다시 켭니다. 정리 자체는 이 키트가 하지 않습니다.

[30] CHKDSK — 책장의 찢어진 페이지 확인
--------------------------------
책장(디스크)의책이 찢어졌거나 페이지가 빠졌는지 검사합니다.
"복구 못 한 조각이 있으면 새 책으로 바꿔 끼우기"까지 합니다.
검사에 2~3분 걸려서 12일에 한 번만 합니다.
이상 있으면: 알려주고, 증상이 심하면 조치를 제안합니다.

[31] BSOD — 쓰러졌을 때 남긴 메모 (파란 화면)
--------------------------------
컴퓨터가 갑자기 파란 화면이 되고 꺼진 적 있나요? 그때 남긴 "왜 쓰러졌는지 메모"가 있습니다.
최근 90일치 메모를 읽어서 원인을 쉽게 풀어 알려줍니다.
이상 있으면: 원인과 해결 힌트를 알려줍니다. (메모를 지우지는 않습니다)

[32] SFC — 레고 설명서와 내 작품 비교  ★ 가장 중요한 검사
--------------------------------
윈도우를 돌리는 데 꼭 필요한 '핵심 시스템 파일'이 손상되거나 변조되었는지 검사합니다.

레고 비유:
  "원래의 레고 조립 설명서(정상적인 윈도우)와 지금 조립된 레고(현재 내 컴퓨터)를
   비교해서, 엉뚱한 블록이 꽂혀 있거나 빠진 블록이 있으면 정상적인 새 블록으로
   교체해 끼워 넣는 작업입니다."

다른 비유: 교과서와 내 필사본을 비교해서 오타를 고치는 것과 같습니다.
검사에 2~4분 걸려서 30일에 한 번만 합니다.
이상 있으면: 알려줍니다. (자동으로 고치지는 않습니다 — 잘못 고치면 더 망가질 수 있어서)

[33] WinSxS — 부품 창고 정리
--------------------------------
윈도우가 업데이트할 때마다 "옛날 부품"을 창고에 남겨둡니다.
필요 없어진 부품을 정리하면 윈도우가 가벼워집니다.
DISM 이라는 도구로 30~60초 걸려서 30일에 한 번만 합니다.
이상 있으면: 정리합니다. (다시 설치할 수 있게 하는 안전장치만 남기고, 완전히 없애지는 않습니다)

[34] TimeSync — 시계 맞추기
--------------------------------
컴퓨터 시계가 1초라도 어긋나면 "인증서 만료", "로그인", "업데이트"가 꼬일 수 있습니다.
세계 표준 시계에 전화해서("pool.ntp.org") 지금 몇 초 차이인지 묻고, 1초 넘게 차이나면 맞춥니다.
이상 있으면: 자동으로 다시 맞추고, 맞춰진지 다시 확인합니다.
주의: 시계 등록을 삭제하는 위험한 명령(w32tm /unregister)은 절대 쓰지 않습니다.

[35] Stability — 최근 7일 일기장
--------------------------------
"어제 어떤 앱이 넘어졌는지" 를 모아본 일기장입니다.
같은 앱이 자주 넘어지면 "이 앱/드라이버 업데이트가 필요해요" 라고 알려줍니다.
한 번 알린 앱은 또 알리지 않습니다(똑같은 얘기 반복 안 함).
이상 있으면: 앱 이름과 충돌 횟수를 알려줍니다.

[36] BootPerf — 아침 출근 시간 측정
--------------------------------
컴퓨터 켜고 바탕화면이 나오기까지 몇 초 걸렸는지 재는 것입니다.
27초면 보통, 2분이면 뭔가 문제입니다.
갑자기 꺼진 기록(Kernel-Power 41)도 최근 7일치에서 찾습니다.
이상 있으면: 알려줍니다.

[37] Updates — 예방접종 (윈도우 업데이트 + 백신)
--------------------------------
윈도우에도 "예방접종"이 있습니다. 새로 발견된 버그/보안 구멍을 막아주는 게 업데이트입니다.
  · 설치 대기 중인 업데이트가 있는지
  · 마지막 업데이트가 너무 오래됐는지(60일 넘으면 경고)
  · 백신(Defender) 약이 3일 넘었는지 → 새 약으로 자동 업데이트
  · 백신 경비원이 꺼져 있으면 → 다시 켜기
  · 재부팅이 필요한데 안 한 상태인지
자동 설치는 기본 꺼져 있습니다(사용자 모르게 재부팅되는 걸 막기 위해).
이상 있으면: 대부분 자동으로 고칩니다.

[38] Auto-Heal — 자동 수리공
--------------------------------
일기장(이벤트 로그)을 보고 "이건 안전하게 고칠 수 있다" 싶은 걸 바로 고칩니다.
  · 스풀러가 멈췄다 → 다시 켜기
  · DCOM 시간 초과가 50건 → 정리하기
  · 검색/오류가 반복된다 → 복구하기
같은 사건을 두 번 고치지 않도록 "여기까지 고쳤어요" 라고 기록해 둡니다(RecordId).
최근 7일치만 보고, 이미 고친 건 다시 손대지 않습니다.

[39] OldDrivers — 오래된 드라이버 설명서 정리  ★ 30일에 한 번
--------------------------------
부품을 설치할 때 창고(드라이버 저장소)에 넣어둔 설명서 중,
"이미 더 새 설명서가 있는데 옛날 설명서도 남아 있는 것"을 찾습니다.
새 설명서를 인터넷에서 찾아오는 게 아니라, **이미 창고에 있는 것들끼리 비교**합니다.
  · 지금 컴퓨터가 쓰고 있는 설명서 → 절대 지우지 않습니다.
  · 컴퓨터가 켜질 때 꼭 필요한 설명서(부팅/키보드/디스크 등) → 절대 지우지 않습니다.
지우기 전에 반드시 목록을 보여주고 "삭제하시겠습니까?" 라고 물어봅니다.
  · y 를 누르면 → 목록 중 지워도 되는 것만 지웁니다.
  · n 이나 Enter 를 누르면 → 아무것도 지우지 않습니다.
  · 예약 자동 점검(사람이 없을 때)에서는 지우지 않고 목록만 결과에 적어둡니다.
결과 파일에는 이렇게 적힙니다:
  "[오래된 드라이버] 새 버전이 있음에도 남아 있는 이전 드라이버 2개 ... [목록]"
  "  · oem3.inf [장치: ACME Gigabit Ethernet] → 최신 ...  ← oem 번호만이 아니라 어떤 장치인지도 적힙니다"
  "삭제: 1개 / 삭제되지 않음: 1개 — 확인해보세요. 직접 실행하여 삭제 질문에 y를 누르면 삭제됩니다."
  (왜 못 지웠는지 이유도 함께 적힙니다)
드라이버 목록은 거의 안 바뀌어서 이 검사는 **30일에 한 번만** 합니다(가장 긴 간격).

[40] UpdateFail — 업데이트 실패 메모 읽기 (숫자 코드 해석)  ★ 매번, 읽기만 함
--------------------------------
윈도우가 업데이트에 실패하면 "왜 실패했는지" 메모를 남겨둡니다.
그 메모를 최근 30일치만 읽어서, 어려운 숫자 코드를 쉬운 말로 바꿔 알려줍니다.
  · 예: 0x80070002 → "필요한 파일을 못 찾았어요 (이전 업데이트가 덜 끝난 경우가 많아요)"
  · 예: 0x800f081f → "업데이트 재료가 없어요 (원본 파일이 빠졌을 때)"
  · 예: 0xc1900101 → "드라이버 때문에 업그레이드가 멈췄어요"
**고치지는 않습니다.** 복구 명령(DISM/sfc)을 자동으로 실행하지 않고, 기록만 결과표에 적습니다.
문제가 계속되면 설정 > Windows Update > 업데이트 기록에서 직접 확인하세요.

================================================================
용어 사전 (어려운 말만 모았습니다)
================================================================

  서비스       = 컴퓨터 안에서 조용히 일하는 작은 프로그램 (경비원, 심부름꾼)
  드라이버     = 부품에게 "이렇게 움직여라" 라고 알려주는 설명서/안경
  캐시         = "다음에 또 쓸지 몰라서" 복사해 둔 임시 보관함
  이벤트 로그  = 컴퓨터가 쓴 일기장 ("몇 시에 뭐가 일어났다" 기록)
  레지스트리   = 컴퓨터 설정을 적어둔 두꺼운 장부
  SMART        = 하드디스크가 스스로 쓴 건강 진단서
  SFC          = 윈도우 핵심 파일을 설명서와 대조해 고치는 검사사
  DISM         = 윈도우 부품 창고 정리 도구
  CHKDSK       = 디스크에 찢어진 페이지가 있는지 검사하는 도구
  WHEA         = 하드웨어가 "아팠어요" 라고 남긴 쪽지
  DNS          = 이름을 주소(번호)로 바꿔주는 전화번호 안내원
  hosts        = 내가 직접 적어둔 주소록
  NTP          = 세계 표준 시계에 물어보는 것
  복원 지점    = "어제 이런 상태였어요" 라고 찍어둔 타임머신 사진

================================================================
결과 파일에서 이런 말이 나오면요
================================================================

  PASS  = 검사 통과! 아무 문제 없습니다.
  WARN  = "이건 확인해 보세요" 라는 뜻. 당장 고장난 건 아닙니다.
  FAIL  = "이건 고쳐야 해요" 라는 뜻. 자동으로 못 고친 항목입니다.
  FIX   = 컴퓨터가 알아서 고쳤다는 뜻. 사용자가 할 일 없습니다.
  SKIP  = "오늘은 안 해도 되는 검사" 라는 뜻 (30일에 한 번 하는 검사 등)

혹시 이상하면요
================================================================

  · "자동 유지보수 점검" 바로가기를 더블클릭하면 지금 바로 다시 점검합니다.
    (영어 윈도우에서는 이름이 "auto-maintenance" 입니다)
  · 백신이 민감하게 반응할 수 있습니다. 이 키트는 서비스·예약 작업·설정을 만지기 때문입니다.
    (사용자 파일을 지우거나 해킹하는 프로그램은 아닙니다)
  · "자동 유지보수 제거" 바로가기(영어: "remove maintenance")는 예약 작업과 바로가기를 없애고,
    광고 설정을 원래대로 되돌립니다.
  · 현재 버전과 다음 버전이 뭐가 다른지 보고 싶으면 "자동 유지보수 버전 안내" 바로가기를 누르세요.
    버튼 화면용 3줄(현재 버전 / 다음 버전 / 예약된 버전 수)이 바탕화면 "자동유지보수_버튼화면.txt" 에 저장되고,
    메모장에 현재 버전 기능과 다음 버전에 추가·변경되는 기능이 정리돼 나옵니다. (Ulanzi 버튼에 연결할 수 있어요)
  · 개발자에게 알려주고 싶으면 "자동 유지보수 피드백" 바로가기(영어: "feedback maintenance")를 누르세요.
    이름·경로 같은 개인정보와 이상한 코드를 지운 안전한 파일을 만들어 줍니다.
    오류 확인용으로 올라가는 내 컴퓨터 정보는 CPU 모델과 GPU 모델뿐이고,
    보고서 구분용 해시 앞 6자리만 함께 올라갑니다. (이름·경로·시리얼·IP 는 지웁니다)
    보내주신 문제는 대부분 다음 버전에서 수정됩니다.
    그런 다음 "GitHub 에 올릴까요?" 라고 물어봅니다.
      - y 를 누르면 → 인터넷으로 자동 올라가고, 피드백 파일은 지워집니다.
      - n 이나 Enter 를 누르면 → 안 올라가고 파일이 바탕화면에 남습니다.
    성공했는지 실패했는지는 바탕화면의 "자동유지보수_피드백상태.txt" 를 열어 보면 알 수 있습니다.

【새 버전이 나왔을 때 (v1.8.0)】
  "자동 유지보수 점검"을 누르면 새 버전이 있는지 인터넷에서 확인합니다.
  새 버전이 있으면 이런 창이 뜹니다:
    "현재 v1.2.0보다 5버전 뒤인 v1.8.0이 나왔습니다. 새로운 기능이 12가지 추가되었습니다."
  · "업데이트" 를 누르면 → 컴퓨터가 알아서 새 버전을 받아 설치합니다.
    설정과 로그는 그대로 이어받고, 기존 폴더는 지우지 않고 남겨 둡니다.
    (혹시 새 버전이 문제면 옛날 폴더로 돌아갈 수 있습니다)
  · "취소" 를 누르면 → 지금 쓰고 있는 버전을 그대로 씁니다.
  · "다시 알리지 않음" 을 누르면 → 그 버전은 더 이상 물어보지 않습니다.
    (그 다음에 더 새 버전이 나오면 다시 알려줍니다)
  직접 받고 싶으면 https://github.com/argenluna/maintenance/releases 에 가면 됩니다.
  참고: 자동으로 실행되는 점검(예약 작업) 때는 이 창이 뜨지 않습니다.
        내가 직접 "점검"을 눌렀을 때만 뜹니다.

【안전하게 받고 설치하는 법 (꼭 읽어주세요)】
  이 프로그램은 예약 작업으로 "관리자 권한"을 받아 스크립트를 실행합니다.
  그래서 아무나 파일을 바꿀 수 있는 곳에 두면 안 됩니다.
  · ZIP 을 받으면 반드시 이 프로그램만 쓰는 새 폴더에 "완전히" 풀어 주세요.
    (예: H:\AutoMaintenance_v1.14.8 — 바탕화면이나 공용 폴더, C:\ 에 그냥 풀지 마세요)
    다른 사람 계정이 이 폴더의 파일을 고칠 수 없도록, 나만 쓰는 개인 폴더에 두세요.
  · 받는 곳은 반드시 공식 주소 https://github.com/argenluna/maintenance/releases 입니다.
    다른 사이트나 이메일 첨부로 받은 파일은 설치하지 마세요.
  · 압축을 풀었을 때 윈도우가 "차단됨" 또는 보안 경고를 띄우면, 받은 곳이 위 주소인지 확인하고
    "차단 해제"를 누르세요. 출처를 모르는 파일이라면 누르지 말고 지우세요.
  · 새 버전 자동 설치도 이제 "검증 표(.sha256)"가 꼭 있는 파일만 설치합니다.
    검증 표가 없거나 내용이 다르면 설치를 중단합니다(기존 버전은 그대로 남습니다).
    다운로드 주소가 중간에 다른 사이트로 넘어가도 설치를 중단합니다.
  · 오래된 버전 폴더는 지우지 않고 남겨 둡니다. 새 버전이 잘 돌아가면 직접 지워도 됩니다.
    단, 옛 폴더 안의 프로그램은 절대 직접 실행하지 마세요(예약 작업은 새 폴더만 씁니다).
  · 컴퓨터를 잘 모르는 사람이 BUILD 서류를 고칠 일은 없습니다. 위 규칙만 지키면 됩니다.
